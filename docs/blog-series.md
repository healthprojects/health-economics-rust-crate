# Blog series plan

Each article should link to the relevant spec and runnable example, disclose
that worked inputs are synthetic, and avoid presenting a threshold as universal.

1. **Why a health-economics crate is mostly tiny pure functions** — contracts,
   composition, denominator guards, and auditability.
2. **ICER and NMB tell the same story differently** — quadrants, dominance,
   thresholds, and why negative ratios mislead.
3. **Positive ROI is not a budget saving** — cash release, capacity value,
   displacement, and budget impact.
4. **Prevalence rules diagnostic value** — sensitivity, specificity, PPV, NPV,
   false positives, and cost per true case.
5. **What uncertainty is worth** — deterministic sensitivity, PSA, EVPI, and
   EVSI without false precision.
6. **Software delivery is an economic system** — cost of delay, CD3, flow,
   DORA, build versus buy, and technical debt interest.

The repository tutorials provide the technical backbone; publication needs an
editorial venue, release date, and reviewer.
