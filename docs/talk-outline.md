# Conference talk outline

## From waiting lists to net monetary benefit in Rust (30 minutes)

1. **The decision, not the formula** — define payer, population, alternatives,
   horizon, and outcome.
2. **A contract per metric** — show how spec, rustdoc, test, and implementation
   agree.
3. **Live calculation** — QALYs → ICER → NMB → break-even price.
4. **The operational trap** — released time is not automatically cash.
5. **Uncertainty** — show a tornado result, acceptability probability, and EVPI.
6. **Engineering mirror** — use cost of delay to prioritize the model itself.
7. **Takeaway** — small transparent functions make assumptions visible; they do
   not make weak evidence strong.

Reserve five minutes for questions. Provide the example and data links before
the talk, use captions, describe charts aloud, and never encode a conclusion by
colour alone.
