# Case studies

These synthetic scenarios show how multiple small metric functions compose into
an auditable decision model. Values are illustrative, not clinical or financial
advice; replace them with locally sourced inputs and preserve units,
perspective, time horizon, and uncertainty assumptions.

- **Hospital capacity and cost:** connect released capacity to operational and
  financial consequences.
- **Digital-health ROI:** separate adoption, realized benefit, and programme
  cost.
- **AI diagnostic tool:** combine diagnostic performance with downstream value
  and harm.
- **Prevention programme:** connect risk reduction, health outcomes, costs, and
  population impact.
